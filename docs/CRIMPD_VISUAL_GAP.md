# CRIMPD VISUAL — gap по экранам (#280)

Цель: Mini App визуально сходится с мобильным UX-языком референса (плотность, иерархия, форма карточек,
отступы, типографика, горизонтальные ряды, sticky-поиск, нижняя навигация, иерархия CTA) — **не** с его
брендом, логотипами, картинками и текстами. Источники: `~/android-ref-lab/HOME_OBSERVATIONS.md`,
`SCREEN_INDEX.md`, `REF_2_1/screens_shareable/` (скриншоты просмотрены напрямую).

Теги: **OBSERVED** — виден на скриншоте/в дампе; **INFERRED** — выведено. Impact: H/M/L.
Снимки «до»/«после»: `scripts/ux_capture.sh` (+ `ux-capture.spec.ts`, тест `capture tabs`) → `/tmp/ux-visual/{before,after}/{390,320}/`
(в репозиторий не коммитятся).

## Решения / отличия по причине

- **Нет героя-фото и фото на карточках** — в модели данных нет медиа (C), чужие изображения не копируем.
- **«Все ›»** — в референсе нет (OBSERVED), но функция есть (#281); оставлена как тихое действие в заголовке, не как CTA.
- **Приветствие скрыто визуально** — сохраняем для скринридеров и старых проверок.
