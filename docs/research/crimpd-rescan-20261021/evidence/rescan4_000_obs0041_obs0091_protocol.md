- Состояние сессии/приложения: чтения до и после холодного перезапуска; порядок вкладок A→B→C; время суток.

## OBS-0041 («Max Hangs», строка «p% of maximum (X kg)»)
| Чтение | Карточка | A 85% | B 90% | C 95% |
|---|---|---|---|---|
| 1 (2026-10-24, ранний проход) | «Max Hangs - 95%» (по умолчанию вкладка C) | **−2 кг** | +29 | +35 |
| 2 | «Max Hangs - 85%» | +24 | +29 | +35 |
| 3 | «Max Hangs - 90%» | +24 | +29 | +35 |
| 4 | «Max Hangs - 95%» | +24 | +29 | +35 |
Сверка (не подгонка): при суммарной нагрузке 70+40=110 → 0.85×110−70 = 23.5 → +24 ✓; 0.90×110−70 = 29 ✓; 0.95×110−70 = 34.5 → 35 ✓ (округление .5 вверх). То же для 7:3s: 50% → −15, 60% → −4, 80% → +18 (rescan3_… workout_protocols). Значение −2 из чтения 1 НЕ воспроизводится в чтениях 2–4 (все три карточки, все вкладки). Значение −2 соответствовало бы результату +10 кг (0.85×80−70), но записи +10 в истории теста нет — причина UNKNOWN. Гипотезы (не проверены): чтение выполнено до полной загрузки результата теста; в тот момент в той же сессии существовали тестовые логи другого теста; кэш. Для объяснения нужен одноразовый аккаунт с известным набором результатов или повтор с записью времени до загрузки.
Статус: формула подтверждена на 3 вкладках ×3 карточках; одно необъяснённое расхождение — UNKNOWN.

## OBS-0091 («Max Hangs - One Arm 85/90/95%»)
| Чтение | Состояние | A 85% | B 90% | C 95% |
|---|---|---|---|---|
| 0 | результата One Arm нет | «85% of max» (без числа) | без числа | без числа |
| 1 | сразу после лога +8 кг | −4 | без числа | без числа |
| 2 | повтор в той же сессии | −4 | без числа | без числа |
| 3 | после холодного перезапуска | −4 | без числа | без числа |
Сверка: A: 0.85×(70+8)−70 = −3.7 → −4 ✓. Для B/C формула дала бы 0.90×78−70 = 0.2 → 0 и 0.95×78−70 = 4.1 → +4; приложение числа НЕ показывает (воспроизводимо во всех чтениях). Гипотезы: нулевое значение скрывается (объясняет B, но не C); B/C привязаны к другому тесту/версии протокола; текст ассистенции в описании B/C (формула с assistance через блок) — ни одна не проверена. Описание B/C содержит собственную арифметику (пример 90% → 54 кг, 95% → 57 кг) — сравнение не выполнялось. Статус: UNKNOWN для B/C; для безопасного объяснения нужен одноразовый аккаунт, где можно задать серию результатов (например +20, +30) и проследить появление чисел.
Лог теста удалён (Logged Workouts пуст), перезапуск выполнен.
