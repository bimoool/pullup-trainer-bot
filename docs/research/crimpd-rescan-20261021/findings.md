# Findings (2026-10-22). Crimpd 8.5.3, Android 15 AVD Pixel 6. Наше приложение НЕ проверялось.

## Факты (OBSERVED)
1. **Замер → нагрузка.** Тренировки «% of test» (подтягивания, висы на пальцах) считают вес = p×(вес тела из настроек + результат теста) − вес тела, округление до кг, отрицательное = помощь; подставляют в лог (OBS-0018, 0019, 0041). Результат теста = максимум в последнем логе теста, виден в Profile (OBS-0020, 0046). Новый слабый результат сразу снижает нагрузку; удаление лога возвращает прежнюю (OBS-0020, 0021). Если результата нет — строка «p% of maximum» без числа и без кнопки (OBS-0042). Часть тренировок — по RPE без расчёта (OBS-0043). Проверено на двух семействах; не вывод для всех.
2. **Шаблон навыка (Base Endurance)** не требует замера (OBS-0003) — вывод ограничен этим шаблоном.
3. **Путь к тренировке:** Главная план не показывает; Plans → план → тренировка → Start = 4 нажатия (Today-вариант не проверен) (OBS-0010).
4. **Правки.** Правка упражнения шаблона применяется сразу, без выбора области; старый лог — снимок (OBS-0016, 0017). Вес подхода 1 перезаписывает следующие (OBS-0022, 0025). Edit Log меняет аналитику через Completion % (OBS-0023). «Только сегодня» отсутствует в проверенных экранах.
5. **Исполнение.** SET>> переносит позицию; пропущенные подходы логируются как выполненные (OBS-0044). Double-tap Save → 2 лога (OBS-0045). Офлайн: плашка ошибки, форма сохранена; повтор после сети дал дубликат (OBS-0030).
6. **Восстановление сессии (Android).** Свернуть/фон — живо, таймер идёт; смахнуть из недавних/force-stop — потеря; крестик окна лога стирает ввод (OBS-0008, 0009, 0024).
7. **Планы.** Один активный; старт с понедельника после конца активного; недельный объём шагом 0.5; фазы Base/Build/Rest/Peak; удаление плана с подтверждением, тренировки — без (OBS-0034…0037, 0050).
8. **Свои упражнения.** Создаются внутри тренировки; Log Resistance + тип ±; не переиспользуются (OBS-0038, 0039, 0049).
