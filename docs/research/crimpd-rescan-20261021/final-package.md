## 1. Подтверждённые возможности и пользовательские пути (Crimpd, Android)
Источник: `findings.md`, `observations.csv` (157 наблюдений), `acceptance-matrix.csv` (23 строки: 14 ВЫПОЛНЕНО / 7 ЧАСТИЧНО / 2 НЕДОСТУПНО), `screen-action-map.csv` (105 строк: 95 воспроизведено / 3 только просмотр или примечание / 7 не выполнено или не применимо), `journeys.md`.
- **Замер → нагрузка.** «% of test» считает вес = p × (вес тела + результат теста) − вес тела; результат = максимум последнего лога теста; удаление лога возвращает прежнюю нагрузку (проверено на двух семействах; для Max Hangs после T3-010 — не подтверждено). Без результата — «p% of maximum» без числа.
- **Путь к тренировке:** Plans → план → тренировка → Start = 4 нажатия; Главная активный план не показывает.
- **Правки:** правка упражнения шаблона применяется сразу без выбора области; вес подхода 1 перезаписывает следующие; Edit Log меняет аналитику; «только сегодня» нет.
- **Исполнение:** пропущенные подходы пишутся как выполненные; двойной Save → 2 лога; офлайн — ошибка, форма сохранена, повтор после сети дал дубль; смахивание из недавних теряет сессию без предложения вернуться.
- **Каталог, поиск, избранное:** поиск × категория × оборудование, избранное и перезапуск; 99 тренировок шаблонов открыты по одной (`template-workouts.csv`, `template-workouts-mechanics.md`).
- **Программы:** 10 шаблонов, 31 уровень, расписания сверены по скриншотам (`schedule-verification.csv`, `templates-matrix.csv`). Тест в расписании зависит от шаблона и уровня.
- **Settings:** шесть грейдов изменены, восстановлены, подтверждены после холодного перезапуска (`rescan6-remainder-checks.md` §3).
- **Веб-версия (my.crimpd.com), БЕЗ входа, не Android:** главная, каталог, Plans (баннер Crimpd+), 404; History/Analytics/Profile без входа рисуют главную. Форма Sign Up (Username, Email, Password) описана, не отправлена — `web-observations-logged-out.md`.
