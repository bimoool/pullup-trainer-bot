# Проверки, требующие реального телефона / другого аккаунта (не блокируют Android-скан)
Выделено по заданию владельца. Эмулятор Android API 35 без звука, одно устройство, один (владельца) аккаунт.

## Реальный Android-телефон
| ID | Проверка | Почему не на эмуляторе |
|---|---|---|
| CR-H01 | Слышимость сигналов GET READY / последние 2 с повтора / последние 5 с отдыха; влияние ползунка Volume | эмулятор запущен с -no-audio; доказано только, что приложение воспроизводит события (dumpsys audio) |
| CR-H02 | Беззвучный режим / DND / громкость мультимедиа = 0 | нет физического переключателя; не оценить слышимость |
| CR-H03 | Вибрация таймера при Vibrations = ON; тактильные тики | на аккаунте владельца Vibrations = OFF (менять его настройку нельзя); вибромотор эмулятора не наблюдаем |
| CR-H04 | Погашенный экран/свёрнутое приложение на реальном устройстве (энергосбережение, убийство процесса), уведомления при разрешённом POST_NOTIFICATIONS | на эмуляторе таймер идёт по часам и сигналы эмитятся, но уведомления отклонены, foreground-сервис не запускался |
| CR-H05 | Наушники/музыка (аудиофокус, приглушение) | нет аудио |
| CR-H06 | Уведомления/часы | нет часов; в приложении не найдено часового интерфейса |
| CR-K04 | Экранная клавиатура поверх форм, safe area, нижние кнопки | эмулятор в режиме аппаратной клавиатуры (плавающая панель, не клавиатура) |

## iPhone (Telegram Mini App — НАША сторона, не Crimpd)
Любой вывод про нашего пользователя на iPhone (наложение кнопок 1RM, окончание таймера, уведомления на часы) из Android-наблюдений Crimpd не следует. Нужны: реальный iPhone + Telegram; список — в issue #359 (L).

## Другой аккаунт / вмешательство в настройки владельца
| ID | Проверка | Что нужно |
|---|---|---|
| CR-A01 / CR-A02 | Первый запуск, регистрация, Climber Profile, онбординг | новый тестовый аккаунт Crimpd на эмуляторе (пароль вводит владелец) |
| CR-K01 | Правила Free vs Plus (создание плана, Premium-тренировки, Favorites) | бесплатный аккаунт |
| CR-K02 | Истечение доступа посреди программы | управляемая подписка/триал (покупки запрещены заданием) |
| CR-K03 (dark) | Тёмная тема | переключение Theme в Settings владельца или второй аккаунт |
| CR-K06 | Смена даты/часового пояса | риск искажения логов владельца; нужен тестовый аккаунт |
| CR-C03 | Путь через блок Today (3 нажатия?) | активный план с занятием на сегодня — только у владельца (одна активная программа) |
| CR-J06 (добавление) | «Add to Plan → Existing» из подборки | селектор по умолчанию = реальный план владельца; нажатие изменило бы его |
