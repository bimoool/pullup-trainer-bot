# Предложения к таблице «Турникмэн — пользовательские пути» (v0.1)
Таблица: https://docs.google.com/spreadsheets/d/1MWPj3ThSCNDu8XYyVWYdOVNdYeepp3saS8TYxu2vBRM/edit
Это ПРЕДЛОЖЕНИЯ исследователя, в таблицу не вносились (правки владельца и навигатора не трогаем). Каждое: ID шага → предложение → причина → доказательство (OBS в observations.csv, сравнение CMP в comparison.csv).
Версия Crimpd 8.5.3, Android. Про наше приложение здесь ничего не утверждается как проверенное.

| Шаг | Предложение | Причина | Доказательство |
|---|---|---|---|
| N05 / X01 | Перед запуском замера показать краткий протокол (когда делать, разминка, как выполнять, критерий остановки, безопасность) и кнопку «Я готов»; полный текст — по ссылке | У Crimpd весь протокол лежит ниже списка упражнений и не повторяется при Start: кнопка ведёт сразу в таймер | OBS-0005, OBS-0006, CMP-002 |
| N05 | Не копировать у Crimpd «замер как обычная тренировка в общем каталоге» — у нас замер встроен в маршрут (решение владельца) | У Crimpd замер отдельная тренировка в Home; шаблон программы замер не требует (проверен один шаблон) | OBS-0003, OBS-0005, CMP-001 |
| N05a / D02 | Автоподстановка прошлого результата — наша собственная функция, у Crimpd образца нет | Crimpd при повторном логировании снова ставит вес 0; прошлый результат не предлагает | OBS-0015, CMP-008 |
| N05 / N06 | Результат замера показывать с итогом «что изменилось в нагрузке и что дальше» | У Crimpd после ввода результата вывода «что дальше» не обнаружено (до сохранения; после сохранения влияние на программу не проверено) | OBS-0007, CMP-003 |
| A01 | Ваши 2 нажатия до старта — короче Crimpd; ориентир Crimpd не подходит | У Crimpd активный план на Главной не виден: Plans → карточка плана → карточка занятия → Start = 4 нажатия (3, если занятие стоит на «Сегодня») | OBS-0010, CMP-006 |
| A02 | «Продолжить» — наше преимущество, не паритет | У Crimpd: свернуть → полоса «Return to workout»; после закрытия приложения продолжения не предложено (Android) | OBS-0008, OBS-0009, CMP-004 |
| A03 | Разделять «отдых» и «занятие без даты» | У Crimpd занятия недели без выбранного дня не попадают в «Today» → пустой экран «No workouts scheduled for today», хотя в неделе 7 сессий | OBS-0010, OBS-0011, CMP-007 |
| A05 / A06 | Не помечать подходы выполненными до выполнения | У Crimpd из окна лога (иконка в плеере) в начале сессии все подходы уже с зелёной галочкой, даже невыполненные | OBS-0013 |
| E02 / E03 | Явный выбор области правки на экране правки с безопасным значением по умолчанию | У Crimpd правка упражнения шаблона применяется сразу без вопроса и без выбора области: меняется только будущее; старые логи — снимки | OBS-0016, OBS-0017, CMP-009 |
| E02 | Нагрузку в предписании показывать явно (у Crimpd её нет) | У Crimpd у пользовательских упражнений нет веса в предписании: вес вводится при логировании с нуля, шаг 1 кг | OBS-0012, OBS-0014, OBS-0015, CMP-008 |
| E06 / A08 | Расписание недели: день + количество — в Crimpd уже есть; помнить сводку «сессий в день» | Редактор «Week N Schedule»: 7 переключателей дней, «+1», итог по дням | OBS-0011, CMP-007 |
| C03 / C04 | Ваш путь («1 меню + 1 выбор») короче Crimpd | У Crimpd создание пользовательской тренировки — 6-шаговый мастер ≈11 нажатий + ввод имени; Save неактивна без имени | OBS-0012 |
| D05 | Исправление прошлого лога — отдельное действие (как у Crimpd Edit Log) | У Crimpd у лога три действия: Edit / Clone / Delete; влияние правки на аналитику пока НЕ проверено | OBS-0014 |
| D01 | «Одна активная программа» — решить явно | Crimpd: «Only one training plan may be active concurrently» (подтверждённое правило Crimpd) | OBS-0004, CMP-005 |

Не проверено (нельзя использовать как факт): влияние Edit Log на аналитику; правка шаблона внутри плана; поведение при отдыхе/пропуске/длительном перерыве; многопрограммность; платные функции.

## Дополнение (2026-10-22, после OBS-0018…0051)
| Шаг | Предложение | Причина | Доказательство |
|---|---|---|---|
| N05 / N05a / D02 | Показывать «результат → нагрузка» и что изменится при замене результата; брать «последний результат» нельзя молча | Crimpd считает нагрузку по ПОСЛЕДНЕМУ логу теста; свежий слабый результат без предупреждения уменьшает нагрузку и удаление лога меняет будущую нагрузку | OBS-0020, OBS-0021, CMP-010 |
| N05 | Подсказка «что делать, если замера нет» — кнопка/шаг, а не текст в описании | У Crimpd без результата теста строка «p% of maximum» без числа; указание про тест — только в тексте описания | OBS-0042, CMP-014 |
| X01 / T05 | Простое объяснение происхождения числа нагрузки («от твоего результата +N и веса тела») | У Crimpd только подпись «90% of 2RM (+47 kg)»; формула (p×(вес тела+результат)−вес тела) выводится только из чисел; НЕ переносить формулу в наш домен автоматически | OBS-0018, OBS-0041, CMP-014 |
| A05 / A07 | Пропуск подхода фиксируется как «пропущено», а не «выполнено» | В Crimpd «SET>>» + автооткрытие лога дают все подходы с галочкой | OBS-0044, CMP-015 |
| A02 | «Продолжить» должно переживать закрытие приложения (смахнуть/остановить) | Crimpd: после смахивания/остановки сессия и ввод теряются; при сворачивании живы | OBS-0024, CMP-013 |
| A07 | Защита от двойного «Сохранить» и понятный статус сети | В Crimpd два быстрых Save → 2 лога; после офлайн-сбоя повтор дал дубликат | OBS-0045, OBS-0030, CMP-016 |
| E02 / E03 | Правка нагрузки в логе не должна перезаписывать другие подходы молча | В Crimpd изменение веса подхода 1 меняет все следующие подходы | OBS-0022, OBS-0025, CMP-011 |
| E06 / D07 | Недоступные даты расписания объяснять причиной | В Crimpd при активном плане все даты серые без пояснения (только общая фраза) | OBS-0037, CMP-017 |
| C02 | Свои упражнения — повторно используемые | В Crimpd они остаются внутри одной тренировки | OBS-0049, CMP-018 |
