## Решение владельца (новое)
**«Сначала согласовываем пользовательский путь, затем отдаём его в код».**
Новые UX-задачи этой инициативы НЕ получают `status:ready` для автоматического кода до явного согласования
пути владельцем в таблице «Турникмэн — пользовательские пути и согласование». Молчание, зелёный тест и
заполненная строка не означают согласования. После согласования версии — её снимок сохраняется в репозитории
и привязывается к задачам реализации.

## Правила доказательности
OBSERVED — проверено непосредственно; INFERRED — предположение; UNKNOWN — не установлено; BLOCKED — не проверено из-за конкретного ограничения.
Недоступность платной функции ≠ её отсутствие. Android ≠ iPhone. Эмуляция WebKit ≠ Telegram на реальном iPhone.
Не декомпилируем приложение, не обходим ограничения доступа. Не обещаем «все сценарии проверены» — есть конечный реестр покрытия (`coverage.csv`).
