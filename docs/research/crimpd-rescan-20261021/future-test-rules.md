# Правила будущих изменяющих тестов (с 2026-10-27, после T3-010)

1. Все изменяющие сценарии — только в тестовом аккаунте Crimpd на эмуляторе `test_pixel6_play`. Аккаунт владельца и эмулятор `ref_pixel6_play` — только чтение.
2. Перед любым тестом записать исходное состояние (назначения, Profile, Test History, настройки, Analytics-метрики) в протокол.
3. После **удаления** тестовой сущности проверять не только её исчезновение, но и возврат зависимых значений: назначения тренировок, Analytics, Profile, настройки — сравнить с исходным: сразу, после холодного перезапуска, после повторного входа.
4. Возврат не подтверждён → в ledger запись «ОТКРЫТО», очистку не называть успешной.
5. Первый тест с новым видом зависимости — на самой свежей учётной записи, один шаг за раз, чтение после каждого.
6. Отправка обращений, Logout, смена пароля, покупки — только с отдельным разрешением владельца.
