# Crimpd → наше

Цель проекта: приложение, **идентичное Crimpd по навигации и фронтенду**, с
нашей начинкой (подтягивания с прогрессией, геймификация, бот, подписка).
Crimpd — не вдохновение, а образец. Если в задаче нет ответа на «как это
должно выглядеть» — смотри сюда; если и здесь нет — **остановись и спроси**,
не додумывай.

## Навигация — пять вкладок, как в Crimpd

**Главная / Планы / Журнал / Аналитика / Профиль**

| Вкладка Crimpd | Что там | Наш экран |
|---|---|---|
| **Home** | Каталог по категориям, поиск «что потренируем сегодня», Мои тренировки, Избранное, Тесты, быстрое «+» | **Главная**: каталог программ + «Мои комплексы» + Избранное + Тесты + виджет «на этой неделе» сверху |
| **Training Plans** | In Progress / Upcoming / Completed, Skill Templates, редактор плана по неделям | **Планы**: текущий план, подключённые курсы, недельная матрица с перетаскиванием |
| **Logbook** | Календарь с точками, список по дням, карточка с Edit / Clone / Delete | **Журнал**: история по месяцам, редактирование, внесение задним числом, клонирование |
| **Analytics** | Круг по типам, столбики по неделям, сводка, экспорт | **Аналитика**: свои SVG + разрез по категориям + экспорт |
| **Profile** | Данные, нормативы, тесты с трендом, настройки | **Профиль**: ГТО/ВСФ, лидерборд, достижения и монеты, тесты, подписка |

## Жёсткие правила

1. **Стартовый экран — Главная-каталог, а не план.** Экран «что осталось на
   неделе» (сделан в волне 4) живёт во вкладке **Планы**, а на Главной от него
   остаётся только небольшой виджет сверху. Приложение, открывающееся сразу на
   форме тренировки, — неверное поведение.
2. **Всё отталкивается от замера.** Нужен снаряд (резина, дополнительный вес) —
   сказать сразу **после замера**, отдельным шагом, а не молча подставить и
   показать на первой тренировке.
3. **Логирование подхода — во время отдыха**, панель раскрывается, как в Crimpd.
   Не отдельный экран после всей тренировки.
4. **Пустые состояния продуманы для каждого экрана.** Нельзя предлагать
   действие, которое гарантированно не может завершиться успехом.

## Только наше — в Crimpd этого нет

Бот с напоминаниями, монеты / достижения / лидерборд, подписка через Robokassa,
`rest_policy` с жёсткой блокировкой для силовых курсов, нормативы ГТО и ВСФ,
автопрогрессия с preview-каскадом, авторизация через Telegram.

## Есть в Crimpd, нам не нужно

Грейды скалолазания, Peer Insights по тестам (отложено), сторонние подборки от
коучей (отложено), логирование кросс-тренинга — его заменяет наш свободный
формат, он уже есть.
